# مصروفي — Masroufi (PWA)

تطبيق ويب يعمل كتطبيق موبايل (PWA): مصروفات شهرية/سنوية/متعددة السنين، كشف حساب PDF، تذكير بالأقساط، عربي/إنجليزي.

## الرفع
ارفع محتوى الفولدر كما هو على أي استضافة **HTTPS** (Netlify / Vercel / GitHub Pages / Firebase Hosting / cPanel).
- Netlify: اسحب الفولدر على app.netlify.com/drop
- Firebase: `firebase init hosting` ثم `firebase deploy`

افتح الرابط من الموبايل ← "تثبيت التطبيق" (أندرويد) أو مشاركة ← "إضافة إلى الشاشة الرئيسية" (آيفون).

## الملفات
- index.html — التطبيق كامل (HTML/CSS/JS بدون build)
- sw.js — Service Worker: يشتغل أوفلاين + إشعارات التذكير
- manifest.json — بيانات التثبيت والأيقونات
- icons/ — الأيقونات

## ملاحظات
- البيانات محفوظة على الجهاز (localStorage). استخدم "نسخة احتياطية" من الإعدادات للنقل بين الأجهزة.
- الإشعارات بتشتغل عند فتح التطبيق، وفي الخلفية على Chrome أندرويد للتطبيق المثبت (Periodic Sync). لتذكير مضمون 100% استخدم زر "للتقويم" في كل تذكير.
- عند تحديث الكود غيّر `VERSION` في sw.js عشان الأجهزة تاخد النسخة الجديدة.
